## Features

- Responsive layout with a mobile navigation menu
- Dark and light themes with a saved preference
- Interactive project cards with mouse, touch, and keyboard support
- Case study pages with screenshot galleries and an expandable image viewer
- Responsive WebP images, lazy-loaded thumbnails, and font loading that lets the page render while fonts download

## Tech Stack

HTML5, CSS3, and vanilla JavaScript. Hosted on Vercel.

## Run Locally

1. Clone or download this repository.
2. Open the `task-01-developer-portfolio` folder in VS Code.
3. Open `index.html` with Live Server.

The portfolio does not require a build step or environment variables.
